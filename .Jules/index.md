## 2026-02-03 - Modernized Sitemap and Robots.txt Configuration **Learning:** Using the `robotsTxtOptions.policies` array and `additionalSitemaps` property in `next-sitemap.config.js` is the modern and preferred way to configure `robots.txt`, replacing the deprecated `transformRobotsTxt` function. This ensures better maintainability and compatibility with `next-sitemap` updates. **Action:** Prefer `policies` over `transformRobotsTxt` for robots.txt customization in future tasks.

## 2026-02-03 - SEO Metadata for Client Components **Learning:** In Next.js App Router, Client Components (using "use client") cannot export `metadata`. To add SEO tags to these routes without refactoring the page, a nested `layout.tsx` (Server Component) should be created in the same directory to export the static `metadata`. **Action:** Use nested `layout.tsx` for metadata in client-rendered routes.
