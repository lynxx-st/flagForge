## 2026-02-05 - Metadata inheritance in Next.js App Router **Learning:** In the Next.js App Router, hardcoding `alternates.canonical` in the root `layout.tsx` causes all sub-pages to inherit that exact URL as their canonical, leading to duplicate indexing issues. **Action:** Remove global canonicals from the root layout and use route-specific `layout.tsx` files (especially for client-side `page.tsx`) to define unique metadata and canonicals.
